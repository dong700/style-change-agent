# 改写功能详解 - 风格标签如何影响改写

##  当前改写流程

### 数据流

```
风格分析 → 风格标签 → 前端展示 → 用户可编辑 → 改写 API → LLM 改写 → 输出结果
     ↓                                              ↑
风格词频 -------------------------------------------+
     ↓                                              ↑
量化特征 ------------------------------------------+
```

### 1. 风格分析阶段

用户上传文档后，系统会分析出：

**LLM 风格分析**（来自 `style_extractor.py`）：
```json
{
  "overall_style_summary": "整体风格描述...",
  "style_labels": [
    {
      "label": "词汇风格：口语化",
      "score": 5,
      "guidance": "依据：使用大量口语词汇..."
    },
    {
      "label": "句法风格：短句主导",
      "score": 4,
      "guidance": "依据：平均句长 10 字..."
    }
    // ... 更多标签
  ],
  "rewrite_suggestions": [...]
}
```

**量化特征**：
- 句法特征（平均句长、句长标准差、标点密度）
- 词汇特征（词汇丰富度、高频词占比）
- 可读性特征（Flesch-Kincaid 等级、被动语态比例）

**风格词频**：
- 过滤后的风格关键词频统计

### 2. 前端展示和编辑

**展示位置**：风格标签 Tab

用户可以看到：

- ✅ 每个标签的评分（1-5 分）
- ✅ 每个标签的依据说明

**用户可操作**：
- ✅ **添加新风格标签**：点击"添加新风格"按钮

- ✅ **删除标签**：点击标签的"删除"按钮
- ✅ **调整评分**：编辑时可以修改评分（1-5 分）

**关键点**：

### 3. 改写阶段

当用户点击"改写"按钮时：

**传递的数据**（第 1324-1329 行）：
```javascript
fetch('/api/rewrite', {
    method: 'POST',
    body: JSON.stringify({
        target_text: targetText,           // 目标文章
        style_labels: styleLabels,         // ⭐ 所有风格标签（用户可编辑）
        style_words: wordFreq,             // 风格词频

```

**重要**：
- ✅ **所有风格标签都会传递给改写器**（`styleLabels` 数组）
- ✅ **包括用户手动添加的标签**
- ✅ **包括用户编辑过的标签**
- ✅ **包括用户调整过评分的标签**

## 核心原则
1. **忠于原意**：保持原文的核心事实、数据、观点不变
2. **风格转换**：全面应用风格标签中的改写指导 ⭐
3. **自然流畅**：改写后的文本要自然、连贯、可读
4. **长度相当**：改写后的文本长度应与原文相当（±20%）

## 小标题风格改写（重要）
原文中如果有小标题，需要根据风格标签调整小标题的风格：
- 典故化标题、事实陈述式、问题导向式、文学化表达、简洁数字式

## 风格应用策略

### 1. 应用风格标签（最重要）⭐⭐⭐
请逐条阅读风格标签，并在改写时有意识地应用：
- 对于每个风格标签，思考"如何在改写中体现这种风格？"
- 将风格指导转化为具体的写作行为
- 例如：
  - "线性编年叙事" → 按时间顺序组织内容
  - "半文半白" → 适当使用文言词汇（约 20%）
  - "权威建构" → 引用数据、文献、专家观点
  - "长句主导" → 多使用 15-25 字的长句

### 2. 参考量化特征（重要）
根据提供的量化特征调整写作：
- 平均句长 → 调整句子长度
- 句长标准差 → 控制句子长度的变化
- 词汇丰富度 → 控制词汇多样性

### 3. 应用风格词频
- 参考"风格词频"中的词汇，在改写中有意识地使用这些词

### 风格标签格式化

`_format_style_labels()` 函数（第 187-200 行）：

```python
def _format_style_labels(self, style_labels: List[Dict[str, Any]]) -> str:
    """格式化风格标签为易读的文本"""
    formatted = []
    for i, label in enumerate(style_labels, 1):
        label_text = label.get('label', '未知')
        score = label.get('score', 0)
        guidance = label.get('guidance', '')
        
        stars = '⭐' * score + '☆' * (5 - score)
        formatted.append(f"{i}. {label_text} {stars}")
        if guidance:
            formatted.append(f"   指导：{guidance}")
    
    return '\n'.join(formatted)
```

**输出示例**：
```
1. 词汇风格：口语化 ⭐⭐⭐⭐⭐
   指导：依据：使用大量口语词汇，如"哎呀"、"我跟你说"等

2. 句法风格：短句主导 ⭐⭐⭐⭐
   指导：依据：平均句长 10 字，多使用句号断句

3. 修辞风格：比喻频繁 ⭐⭐⭐⭐⭐
   指导：依据：多处使用明喻、暗喻
```

##  用户自定义风格标签

### 添加新风格标签

**前端操作**：
1. 点击"添加新风格"按钮
2. 输入标签名称（如"幽默风格"）
3. 设置评分（1-5 分）
4. 输入改写指导（如"多使用双关语和夸张修辞"）
5. 点击保存

**数据流**：
```javascript
// 用户添加的标签会进入全局变量
styleLabels.push({
    label: "幽默风格",
    score: 4,
    guidance: "多使用双关语和夸张修辞"
})

// 改写时会传递给后端
fetch('/api/rewrite', {
    body: JSON.stringify({
        style_labels: styleLabels  // 包含用户添加的标签
    })
})
```

**改写器会应用**：
- ✅ LLM 分析出的原始标签
- ✅ 用户手动添加的标签
- ✅ 用户编辑过的标签
- ✅ 所有标签的评分和指导

### 实际应用场景

#### 场景 1：增加特定风格

**需求**：想让文章更正式一些

**操作**：
1. 分析文档后，看到当前风格标签
2. 点击"添加新风格"
3. 添加标签：
   - 标签名：`正式书面语`
   - 评分：`5`
   - 指导：`使用书面化词汇，避免口语化表达，多用复合句`
4. 点击改写

**结果**：改写器会应用这个新增的正式风格标签

#### 场景 2：调整风格强度

**需求**：觉得某个风格不够强

**操作**：
1. 找到该风格标签
2. 点击"编辑"
3. 将评分从 3 提高到 5
4. 保存

**结果**：改写器会更强调这个风格（因为评分高）

#### 场景 3：删除不需要的风格

**需求**：某个风格不适合目标场景

**操作**：
1. 找到该风格标签
2. 点击"删除"
3. 确认删除

**结果**：改写器不会应用这个被删除的风格

##  改写器如何使用风格标签

### 标签应用机制

改写器接收到风格标签后，会：

1. **逐条阅读标签**
   ```
   请逐条阅读风格标签，并在改写时有意识地应用
   ```

2. **将标签转化为具体行为**
   ```
   - "线性编年叙事" → 按时间顺序组织内容，使用"首先...然后...最后"
   - "半文半白" → 适当使用文言词汇（约 20%），如"乃"、"遂"、"盖"
   - "权威建构" → 引用数据、文献、专家观点增强可信度
   - "长句主导" → 多使用 15-25 字的长句，通过连词连接多个分句
   ```

3. **考虑评分权重**
   - 评分 5 分：必须严格应用
   - 评分 3-4 分：适度应用
   - 评分 1-2 分：轻微应用或忽略

4. **遵循改写指导**
   ```
   指导：依据：使用大量口语词汇...
   → 改写时有意识地使用口语词汇
   ```

### 多维度标签应用

**示例标签组合**：
```
1. 词汇风格：口语化 ⭐⭐⭐⭐⭐
   指导：使用"哎呀"、"我跟你说"等口语词

   指导：平均句长 10 字左右，多使用句号

   指导：每段至少使用 1-2 个比喻

4. 语气与情感：幽默 ⭐⭐⭐⭐
   指导：适当加入双关语和夸张
```

**改写器会同时应用所有标签**：
- ✅ 使用口语化词汇
- ✅ 写短句（10 字左右）
- ✅ 每段加比喻
- ✅ 加入幽默元素

##  总结

### 风格标签流向

```
用户添加/编辑的标签 ──
                       ↓
LLM 分析的标签 ────────→ styleLabels 数组 ──→ 改写 API ──→ LLM 应用所有标签
                       ↑
用户删除的标签 ────────┘（不会传递）
```

### 关键点

1. **所有可见的标签都会用于改写**
   - ✅ LLM 分析的标签
   - ✅ 用户添加的标签
   - ✅ 用户编辑的标签
   - ❌ 用户删除的标签（不会传递）

2. **评分影响强度**
   - 5 分：严格应用
   - 3-4 分：适度应用
   - 1-2 分：轻微应用

3. **改写指导很重要**
   - 告诉 LLM 如何具体应用这个风格
   - 越具体，效果越好

4. **可以自定义风格**
   - 添加新标签实现特定风格
   - 编辑标签调整风格强度
   - 删除标签移除不需要的风格

### 使用建议

**为了获得最佳改写效果**：

1. **仔细审查 LLM 分析的标签**
   - 删除不准确的标签
   - 调整评分反映真实需求

2. **添加自定义标签**
   - 针对特定场景添加风格
   - 提供具体的改写指导

3. **平衡标签数量**
   - 太多标签可能冲突
   - 保留最重要的 10-15 个标签

4. **提供清晰的指导**
   - 指导越具体，改写越准确
   - 例如："每段使用 1-2 个比喻"比"多用修辞"更好

这样，你就可以完全控制改写的风格了！🎉
