# 超大文本处理模块 - 风格标签编辑功能说明

## 改进说明

根据你的建议，我已经修改了超大文本处理模块，现在的流程是：

### ✅ 新的工作流程

```
1. 上传源文档
   ↓
2. 自动分析并提取风格标签
   ↓
3. 【新增】查看和编辑风格标签 ⭐
   - 查看所有风格标签
   - 编辑标签名称、评分、指导
   - 删除不需要的标签
   - 添加新的风格标签
   ↓
4. 保存分析结果
   ↓
5. 上传目标文档
   ↓
6. 使用编辑后的风格标签改写
```

## 新增功能

### 1. 风格标签查看

处理完源文档后，会自动显示提取的风格标签：

```
🏷️ 风格标签（可编辑）
┌────────────────────────────────────┐
│ 词汇风格：口语化          ⭐ 5/5   │
│ 依据：使用大量口语词汇...          │
│ [✏️ 编辑] [🗑️ 删除]               │
└────────────────────────────────────┘
```

### 2. 编辑风格标签

点击"编辑"按钮，可以修改：
- **标签名称**：如"词汇风格：口语化"
- **评分**：1-5 分（影响改写强度）
- **改写指导**：描述如何在改写时体现这种风格

### 3. 删除风格标签

点击"删除"按钮，可以删除不需要的风格标签。

### 4. 添加风格标签

点击"添加风格标签"按钮，可以添加自定义风格：
- 输入标签名称
- 设置评分
- 输入改写指导

### 5. 保存编辑后的风格

点击"保存分析结果"时，会同时保存编辑后的风格标签。

### 6. 使用编辑后的风格改写

改写目标文档时，会使用编辑后的风格标签，而不是原始提取的风格。

## 使用示例

### 场景：删除不需要的风格

**问题**：LLM 分析出"半文半白"风格，但你不想要这个风格。

**操作**：
1. 处理源文档后，查看风格标签
2. 找到"半文半白"标签
3. 点击"删除"
4. 保存分析结果
5. 改写时不会应用这个风格

### 场景：调整风格强度

**问题**：某个风格评分太高，改写时会过度强调。

**操作**：
1. 找到该风格标签
2. 点击"编辑"
3. 将评分从 5 改为 3
4. 保存
5. 改写时会适度应用这个风格

### 场景：添加自定义风格

**问题**：想要添加一个特定的风格要求。

**操作**：
1. 点击"添加风格标签"
2. 输入：
   - 标签：`修辞风格：比喻频繁`
   - 评分：`5`
   - 指导：`每段至少使用 1-2 个比喻，增强形象性`
3. 保存
4. 改写时会应用这个自定义风格

## 技术实现

### 前端（large_text.html）

**新增变量**：

**新增函数**：
- `loadStyleLabels(analysisId)` - 加载风格标签

- `deleteStyleLabel(index)` - 删除风格标签
- `saveStyleLabel()` - 保存风格标签
- `closeStyleModal()` - 关闭模态框

**新增 UI**：
- 风格标签显示区域
- 编辑模态框
- 添加、编辑、删除按钮

### 后端（large_text_api.py）

**新增 API**：

1. **GET /style_labels/<analysis_id>**
   - 获取风格标签
   - 返回：`{'success': True, 'style_labels': [...]}`

2. **POST /style_labels/<analysis_id>**
   - 更新风格标签
   - 参数：`{'style_labels': [...]}`
   - 返回：`{'success': True}`

**修改逻辑**：
- `saveSourceAnalysis()` - 保存时先更新风格标签
- `process_target_task()` - 改写时使用更新后的风格标签

## 使用建议

### 1. 先分析再改写

**推荐流程**：
```
1. 处理源文档
2. 仔细查看风格标签
3. 删除不准确或不想要的标签
4. 调整评分（过高或过低）
5. 添加自定义风格要求
6. 保存
7. 改写目标文档
```

### 2. 风格标签数量

- **建议**：保留 10-15 个最重要的风格标签
- **避免**：太多标签可能导致冲突
- **优先**：保留评分 4-5 分的标签

### 3. 评分调整

- **5 分**：必须严格应用（如"正式书面语"）
- **3-4 分**：适度应用（如"偶尔使用比喻"）
- **1-2 分**：轻微应用或忽略

### 4. 改写指导

**好的指导**：
```
每段使用 1-2 个比喻，增强形象性
平均句长控制在 15-20 字
使用"首先...其次...最后"结构
```

**不好的指导**：
```
多用修辞
句子不要太长
注意结构
```

**区别**：好的指导具体、可操作；不好的指导模糊、难以执行。

## 常见问题

### Q1: 编辑后的风格标签会覆盖原始分析吗？

**A**: 是的。编辑后保存会更新原始分析结果，改写时会使用编辑后的风格标签。

### Q2: 可以恢复删除的风格标签吗？

**A**: 不可以。删除后需要重新处理源文档或手动添加。

### Q3: 风格标签的评分如何影响改写？

**A**: 评分越高，改写时越强调这个风格。5 分会严格应用，1-2 分可能被忽略。

### Q4: 添加的自定义风格和 LLM 分析的风格有区别吗？

**A**: 没有区别。改写时一视同仁，都会应用。

### Q5: 可以保存多个版本的风格标签吗？

**A**: 目前不支持。每次保存会覆盖之前的版本。建议保存前仔细确认。
